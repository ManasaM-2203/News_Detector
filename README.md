📰 Fake News Detector

A machine learning–powered web application that predicts whether a news article is real or fake using Natural Language Processing (NLP). Built with Streamlit for the frontend, it leverages a Decision Tree Classifier and TF-IDF vectorization for classification.

🚀 Features

1. Detects fake vs. real news in real-time
2. Trained with benchmark datasets (PolitiFact & GossipCop)
3. NLP preprocessing using NLTK
4. Decision Tree Classifier for interpretable predictions
5. Interactive Streamlit app for easy usage

🧠 Tech Stack

Programming Language: Python
Frontend: Streamlit
ML Libraries: scikit-learn, pandas, numpy
NLP: NLTK
Model: Decision Tree Classifier
Deployment Ready: Requirements included for Streamlit deployment
